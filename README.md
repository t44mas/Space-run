1. Описание игры «Space-run»:
«Space-run»: Это маленькая аркадная игра, где игроку предстоит управлять космическим кораблём, который должен уничтожить вражеские корабли и убить главного босса . Враги будут лететь по разным траекториям и пытаться сбить корабль игрока. Игрок должен уворачиваться и стрелять по врагам. Так же в этой игре будут разные улучшения, которые помогут при прохождении. В этой игре будут несколько типов врагов и финальный босс, анимации взрыва и различные звуковые эффекты 

2. Техническое задание:
1. Создание структуры игры
   	 1) создание файла config.py
    		здесь находятся все глобальные переменные, путь к дб, и настройки игры
	 2) создание файла classes.py
   		здесь все классы, некоторые функции, и инициализация различных групп спрайтов и общего колва очков Scor:
	     	a) функция load_image для загрузки изображений
	   		b) функция records для записи результатов
	     	c) class MainShip:
	    		1. метод update здесь проверяем коллизию, hp и другое 
	      		2. метод handle_input для движения
	      		3. main_ship_shooting для стерльбы
		d) class EnemyShip:
			1. метод update здесь проверяем коллизию, hp и другое 
	      		2. метод startAnim для движения
	      		3. enemy_shooting для стерльбы
	    	e) class BigEnemyShip:
	      		1. метод update здесь проверяем коллизию, hp и другое 
	      		2. метод change_dir для рандомного смены направления 
	      		3. enemy_shooting для стерльбы
	      		4. check_out_of_bounds для переноса врага вверх
	    	f) class Rocket:
	      		1. update здесь проверяем коллизию, hp и считаем траекторию движения
	   	g) class Laser:
	      		1.update для нанесения урона
	   	h) class Alarm - предупреждение о лазере
		i) class SmallEnemy:
			1. метод update здесь проверяем коллизию, hp и другое 
	      		2. метод change_dir для рандомного смены направления 
	      		3. enemy_shooting для стерльбы
	      		4. check_out_of_bounds для переноса врага вверх
	   	g) class Bullet:
	   		1. update для смены направления движения у пуля если вражеская
		k) class HP - для отображения hp
		l) class Points - для отображения очков
		m) class SpeedBoostHP - для отображения ускорения 
		n) class HPBoost - для появляющихся хилок
		o) class Boom:
	      		1. метод update здесь вызываем boom()
	      		2. метод cut_sheet для делания анимации
	      		3. метод boom() для самой анимации взрыва
	   	p) class Boss:
	      		1. метод update здесь проверяем коллизию, hp и другое 
	      		2. метод laser_attack для атаки Laser() 
	      		3. bounce_attack для стрельбы отскакивающимися пулями 
	      		4. startAnim для движения
	    	q) class BounceBullet:
	      		1. update для смены пуль которые будут отскакивать от стен
	    	r) class Score:
	      		1. clear для очистки всех рез-ов о игре
 	3) Создание файла levels.py:
		В нем находятся глоб переменные событий, разные функции для экранов игры:
		a) start_screen - стартовый экран
		b) get_top_scores - функция последних рекордов
		c) draw_text - вспом. функция для get_top_scores
		d) lose_screen - экран поражения
		e) level_one - первый уровень со всеми врагами, событтиями, волнами
		f) boss_level - босс со всеми врагими, событиями
	4) Создание main.py
		В него импортируется почти все остальное, инициализируется pygame и происходит обработка событий "game", "boss", "lose",  'records',  "menu",  "exit"
Интерфейс игры:
	1. Начальный экран
	2. 1 Уровень
	3. Босс уровень
	4. Финальный экран (Поражение / Победа)
	5. Рекорды игр
